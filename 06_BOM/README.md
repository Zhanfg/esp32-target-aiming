# 06_BOM

物料清单放这里，主文件是 `bom.csv`。规格书 §21 给的是设计预算，不是实时市场报价，单位是人民币。
表里没有逐项数量、单价、供应商、替代料这些字段，因为 §21 只给了分类成本区间，规格书未给的信息就不编造。
等实际询价后再决定要不要加这些列。

## 这份 BOM 是什么

它是设计阶段的预算口径，用来判断机械方案有没有超 ¥50，不是采购单。各列含义如下。

- `item`：项目名称。
- `category`：口径分组。取值有几类：`炮头机械架构`（计入 ¥50）、`不计入¥50-后台或外设`、`汇总`、`核算`、`预算规则`（规则与说明行不参与求和）。
- `target_cost_cny_min` / `target_cost_cny_max`：规格书 §21 给的目标成本区间。规格书未给成本的行留空。
- `counted_in_50`：这一行是否计入 §1.1 的 ¥50 炮头机械架构预算。机械件为 `yes`，后台外设为 `no`，规则与汇总行留空。
- `included_in_quote`：这一行是否出现在本次 ¥50 报价核算口径内。与 `counted_in_50` 一致，机械件 `yes`，后台外设 `no`。
- `note`：口径说明、默认决策或引用出处。

## 范围边界（§1.1）

计入 ¥50 的只有炮头机械架构本身。CSV 里 `counted_in_50=yes` 的 9 行就是全部：弹性片、膜片材料、轴/销/铜套、小轴承（如果确有必要）、小磁铁、O 型圈/密封件、M2/M3 紧固件、软质实验载荷、其他机械杂件。

不计入 ¥50 的按原清单完整列出，`counted_in_50=no`：MCU、主控板、传感器后台、云台舵机、云台电机、发射/蓄能所用外部执行电机或舵机、电源、PCB、线材、通信模块、3D 打印材料成本、CAD/仿真/实验仪器成本。这些行成本留空，标了「规格书未给」。

3D 打印材料不计入 ¥50。打印件只负责框架、支撑、限位、边界切换、模块定位，不能因为打印便宜就改机械方案。

## 核算结果

按 CSV 中 `counted_in_50=yes` 的 9 行求和：

- 下限合计 = 3+2+2+2+1+2+2+1+2 = **¥17**
- 上限合计 = 8+5+5+8+3+5+4+3+5 = **¥46**

§21 的目标总计为 ¥17–46，两边对上。推荐 ≤ ¥40，硬限制 < ¥50。上限 46 低于硬限制，但高于推荐值 40，所以按上限采购时要先按下面的顺序压。

## 超预算削减顺序（§21）

按顺序执行，前面能解决就不动后面的：

1. 先减非必要轴承。低载荷小角度优先铜套或打印导向。
2. 再减 CNC/金属定制件。改用打印件或标准件。
3. 再减多余装饰壳。
4. 最后减不必要传动级。

有四项不得删减：状态检测、防脱结构、必要密封、安全互锁。CSV 底部四行 `不可删减-*` 记录了这条约束。

## 更新时机

- 实际询价后：更新单价与供应商信息，历史价格留在 note 里并写询价日期。
- `03_CAD/` 出图后：按图纸核对件数与规格，确认没有多买或漏买。
- 结构冻结后：确认实际选型仍落在 ¥50 内，并把与设计预算的偏差记进 note。
- 整合成本核算以这份表为准。
