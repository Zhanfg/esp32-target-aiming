# MST-01 需求规格（REQUIREMENTS.md）

本文件对应主规格 §32 TASK-01 与 §33 交付项。需求从
`00_MASTER_SPEC/MST-01_Offline_Agent_Master_Spec_v2.0.md` 提取；凡与规格书叙述冲突处，
按 `00_MASTER_SPEC/统一架构方案.md` 的已冻结裁决处理，裁决结果在第三部分列出。

## 文档约定

- 需求编号 `REQ-nnn` 全局唯一，按主题分组连续编号。
- 类型含义：
  - `MUST`：必须满足，验收不通过即缺陷。
  - `MUST NOT`：禁止项。
  - `SHOULD`：建议；偏离时需在 `DESIGN_DECISION_LOG.md` 记录理由。
  - `MAY`：允许项，不作为强制验收。
- 来源写章节号，如 §11 Interlock 3，便于回溯。
- 需求正文按可验收方式重写，不照抄规格书叙述。

## 8. 状态机

| 编号 | 类型 | 需求 | 来源 |
|---|---|---|---|
| REQ-052 | MUST | 主状态序列为 BOOT → SAFE → HOME → READY → AIM_ALLOWED → PRELOAD → ARMED → RELEASE → RECOVER → INDEX → READY。 | §10.1 |
| REQ-053 | MUST | 任意状态发生异常时进入 FAULT，FAULT 之后回到 SAFE。 | §10.1 |
| REQ-054 | MUST | 状态机分为发射周期区与指向质量区两个区域，各自维护转移表，跨区用守卫矩阵约束；不得压平为单一枚举表达全部组合。 | §10.1，统一架构 §6.1（裁决） |
| REQ-055 | MUST | `AIM_ALLOWED` 在指向质量区处于 `LOCKED` 时授予，`LOCKED` 是持续评估的质量谓词，不是一次性事件。 | 统一架构 §6.2 |
| REQ-056 | MUST | `RELEASE` 前重新确认 `LOCKED`；`PRELOAD → ARMED` 不要求持续 `LOCKED`，但预载未完成而 `LOCKED` 丢失超过中止窗口时退回 `READY` 并受控卸载。 | 统一架构 §6.2 |
| REQ-057 | MUST | 标定态限制在 `READY` 及以下：`CALIBRATING`/`CALIB_MODE` 期间禁止 `READY → AIM_ALLOWED`，且只能从 `READY` 发起标定。 | 统一架构 §6.3 |

## 9. 安全互锁

| 编号 | 类型 | 需求 | 来源 |
|---|---|---|---|
| REQ-058 | MUST | Interlock 1：`MECH_RECOVERED` 为 TRUE 时才允许进入 `PRELOAD`。 | §11 Interlock 1 |
| REQ-059 | MUST | Interlock 2：`MAG_INDEX_OK` 为 TRUE 时才允许执行 Mode B 动作。 | §11 Interlock 2 |
| REQ-060 | MUST | Interlock 3：`FIRE_INHIBIT` 为 TRUE 时 `RELEASE` 永久禁止。 | §11 Interlock 3 |
| REQ-061 | MUST | Interlock 4：`FAULT` 后必须重新 `HOME`。 | §11 Interlock 4 |
| REQ-062 | MUST | 四条互锁必须有硬件实现，软件只作第一道闸与诊断；释放能量路径由物理与门串在供电回路中。 | §10.4，统一架构 §6.5、§6.6 |
| REQ-063 | MUST | 释放门控条件同时满足：`FIRE_INHIBIT` 未断言、`EXTERNAL_ALLOW` 有效、`MECH_RECOVERED`、Mode B 载荷对齐、`ARMED` 锁存、主使能有效；任一不满足则释放回路物理断开。 | 统一架构 §6.5 H1 |
| REQ-064 | MUST | 机构未复位时预载执行器无法被驱动，通过常闭触点实现。 | 统一架构 §6.5 H2 |
| REQ-065 | MUST | 故障与急停状态锁存，复位条件接 `PAN_HOME`、`TILT_HOME`、`MAG_HOME` 三处零位开关的与。 | 统一架构 §6.4、§6.5 H4 |
| REQ-066 | MUST | `FAULT` 锁存且不自动恢复，唯一清除路径为 `SAFE → HOME → READY`，不存在 `FAULT → READY` 这条边。 | 统一架构 §6.4（裁决） |
| REQ-067 | MUST | 释放命令的驱动时间由硬件单稳态钳位，即使 MCU 卡在高电平也只产生固定短脉冲，不会持续通电。 | 统一架构 §6.6 |
| REQ-068 | MUST | `FIRE_INHIBIT` 与 `EXTERNAL_ALLOW` 的失效方向指向安全，断线、掉电、接插件松脱均落到禁止侧。 | 统一架构 §6.7 |
| REQ-069 | MUST | 机械限位用物理止挡，主电源急停用常闭蘑菇头直接串执行器供电，不经过 MCU。 | 统一架构 §6.5 H5、H6 |
