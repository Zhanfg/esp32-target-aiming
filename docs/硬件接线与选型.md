# 硬件接线与选型

上电前的检查依据。引脚以 `firmware/include/config.h` 为准，但必须对照实物原理图逐条核对过
才能烧录。

## 1. 物料清单

| # | 部件 | 规格 | 数量 | 备注 |
|---|---|---|---|---|
| 1 | 主控 | ESP32-S3 DevKitC-1，N16R8，16MB Flash / 8MB OPI PSRAM | 1 | 必须选带 PSRAM 的版本，否则放不下图像帧 |
| 2 | 摄像头 | OV2640 或 OV5640 模组 | 1 | OV2640 驱动最稳，建议先用它跑通 |
| 3 | 减速电机 | JGB37-520，12V，带霍尔编码器 | 2 | pan 与 tilt 各一，记下减速比 |
| 4 | 电机驱动 | TB6612FNG 模块 | 1 | 双路，一片驱两轴 |
| 5 | 电源 | 12V 2A 以上直流 | 1 | 电机供电 |
| 6 | 电源 | 5V / 3.3V 稳压，可由 12V 降压 | 1 | 逻辑供电 |
| 7 | 电容 | 电解 470µF 以上，25V | 1 | 并接在 TB6612 的 VM 与 GND 之间，吸收换向尖峰 |
| 8 | 电容 | 0.1µF 陶瓷 | 若干 | 各电源引脚就近去耦 |
| 9 | 激光模组 | 3.3V 或 5V 可驱动，带使能 | 1 | 作发射器占位负载 |
| 10 | 限位开关 | 机械或光电，常闭 | 2 | 可选，硬件限位双保险 |

JGB37-520 是个统称。市面上有 30、56、90 等多种减速比，编码器 PPR 也有 11 和 13 两种。
这两个数字填错，整条角度链会按比例偏。以实物铭牌或实测为准。

## 2. 引脚分配

`config.h` 里给了建议默认值，但不同 ESP32-S3 开发板的可用 GPIO 不一样。对照你的板子原理图，
把下表填完并与 `config.h` 对齐。

| SIOD (SDA) | | ☐ | |
| SIOC (SCL) | | ☐ | |

| D7..D0 | | ☐ | 8 根数据线 |

摄像头占 12 根以上信号线，最容易跟电机、编码器抢引脚。ESP32-S3 的 GPIO 26 到 32 常被内部
Flash 和 PSRAM 占用，GPIO 33 到 37 在部分开发板上不可用。先把摄像头引脚定死，再分配电机
和编码器。

### 2.3 编码器

每轴一套。

| 信号 | 说明 | pan GPIO | tilt GPIO | 备注 |
|---|---|---|---|---|
| A 相 | 正交 A | | | 接 PCNT 单元 |
| B 相 | 正交 B | | | |
| VCC | 编码器供电 | 不适用 | 不适用 | 通常 3.3V 或 5V，按模组规格 |
| GND | 地 | 不适用 | 不适用 | 与 MCU 共地 |

编码器是开漏输出时必须加上拉。内部上拉通常够用，走线长的话建议外接 4.7kΩ。
A、B 两根线远离电机线，有条件的用屏蔽线或双绞线。

## 3. 供电与接地

```
                        ┌─────────────┐
  12V DC ──┬──────────► │  VM         │
           │            │  TB6612FNG  │
           │            │             │
           ├──[470µF]───┤  GND        │
           │            └──────┬──────┘
           │                   │
           ▼                   │
     ┌───────────┐             │
     │ 12V→5V/3.3V│             │
     │   降压模块  │             │
     └─────┬─────┘             │
           │                   │
           ▼                   ▼
     ┌──────────────────────────────┐
     │   ESP32-S3   GND ●━━━━━━━━━━ GND
     └──────────────────────────────┘
                  ▲
                  └── 单点共地，不要形成地环路
```

电机和逻辑分开供电，只在一点共地。多处共地会形成地环路，引入干扰。

TB6612 的 VM 与 GND 之间要并一个 470µF 以上的电解电容。有刷电机换向时会产生大电流尖峰，
电源会瞬间跌落，症状就是一转电机 ESP32 就复位。

电机线不要和编码器线、摄像头排线并行捆扎。电机线是主要噪声源，并行布线会把噪声耦合进信号线，
表现为编码器计数跳变或者图像撕裂。

常见故障对照：

| 症状 | 最可能原因 | 对策 |
|---|---|---|
| 电机一转就复位 | 电源跌落或地环路 | 加大电容，分供电，单点共地 |
| 编码器计数乱跳 | 噪声耦合或缺上拉 | 编码器线远离电机线，加上拉，加屏蔽 |
| 图像撕裂或有横纹 | 电源噪声或 PSRAM 带宽不足 | 加去耦电容，降分辨率，降帧率 |
| 电机不动但发热 | STBY 没拉高，或方向脚冲突 | 检查 STBY 电平和 IN1、IN2 逻辑 |
| 只往一个方向转 | 方向脚接线错，或极性标志错 | 检查 `MOTOR_INVERT_*` 与 IN1、IN2 |
| 角度符号整体相反 | 编码器 A、B 接反 | 交换 A、B，或翻转 `MOTOR_INVERT_*` |

## 4. TB6612FNG 真值表

| STBY | IN1 | IN2 | PWM | 电机状态 |
|---|---|---|---|---|
| H | H | H | 不适用 | 刹车，短接绕组 |
| H | L | L | 不适用 | 滑行，断开 |
| H | H | L | PWM | 正转，速度正比于占空比 |
| H | L | H | PWM | 反转，速度正比于占空比 |
| L | 不适用 | 不适用 | 不适用 | 待机，断电 |

STBY 交给 MCU 控制，这是紧急停止的最后一道闸。急停时拉低 STBY 可以直接切断电机动力。

PWM 用 20kHz，超出人耳可听范围，避免电机啸叫。

刹车和滑行的选择：需要快速停止用刹车，需要减小机械冲击用滑行。

## 5. 上电检查清单

按顺序做，不要跳步。

- [ ] 不接电机，只上电逻辑侧，确认 ESP32 正常启动，串口有输出
- [ ] 确认 PSRAM 被识别，setup 会打印 PSRAM 大小
- [ ] 万用表确认 12V 和 3.3V 各自正常，逻辑侧没有被灌进 12V
- [ ] 确认所有模块共地
- [ ] 烧录编码器验证程序，手动把舵盘转一整圈，打印计数值
      - 实测 count 应该等于 `PPR × 4 × 减速比`
      - 差整数倍说明 PPR 或减速比填错
      - 符号相反就交换 A、B，或者翻转极性宏
- [ ] 接上电机，先只给 5% 占空比，确认转向与编码器读数符号一致
- [ ] 测软限位，手动逼到极限角，确认程序限幅而不是硬顶
- [ ] 测急停，调用 `turretEmergencyStop()`，确认电机立即断电
- [ ] 最后才接发射器，先确认没调 `arm()` 时 `fire()` 一定失败

## 6. 机械装配

| 项 | 要求 |
|---|---|
| 舵盘与电机轴 | 刚性连接，联轴器或直接压装。弹性连接会引入回程误差 |
| 转动惯量 | 摄像头和发射器尽量靠近旋转轴，减小惯量和振动 |
| 配重 | 重心偏离转轴时要配重，否则停止时有下垂和振荡 |
| 线缆 | ±180° 方案要留够线缆余量并固定，避免转动时扯断 |
| 限位 | 机械限位是最后防线，软限位要在机械限位之前生效 |
| 减速箱背隙 | 背隙是主要误差源，见[标定与几何推导](标定与几何推导.md)第 11 节 |

## 7. 以后扩展到 360° 连续旋转

现在按 ±180° 有限角度实现，代码里用 `ANGLE_WRAP_360_ENABLED` 预留了环绕能力。
升级到连续旋转要额外解决几件事。

| 问题 | 方案 |
|---|---|
| 线缆缠绕 | 加滑环（集电环）；或者摄像头改无线图传、电机改电池供电 |
| 角度参考 | 需要绝对值参考。滑环通道不够时用光电零点开关做每圈校准 |
| 角度跳变 | 打开 `ANGLE_WRAP_360_ENABLED`，所有角度比较走环绕分支 |
| 电机选型 | 要能长时间单向旋转，注意有刷电机的电刷寿命，或者换无刷 |

控制层现在就写成环绕感知的，原因在这里。机械改造是后话，但这一层抽象现在不做，将来就要
返工重写。
