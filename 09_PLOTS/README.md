# 09_PLOTS

实验与仿真的图表。数据从 `08_DATA/` 来，流程和参数写进文件名或同目录的说明，保证换个人能重画。

常用的几张：

- 力-位移曲线，标出 snap point 与两级顺序，对应 §23.1
- snap 后速度与 stage interval 的时间曲线，对应 §23.2
- 重复性：同一条件下的多周期叠加，看散布
- 参数扫描的等高线或趋势图，变量同 §23.3
- 边界状态与机械响应的对照图，服务 MST-01D

图只放结果，推导不在这里。公式与误差预算在 `02_REQUIREMENTS/`，模型细节在 `04_SIMULATION/`。引用
某张图时用相对路径，不要把图复制到论文目录再各自维护。
