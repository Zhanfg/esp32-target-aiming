# 11_PUBLICATION_NOTES

论文、专利与技术披露的记录。规格书 §20 定义了这个目录，§33 要求交付，本目录当前有两份文档加这份说明。

## 这个目录放什么

- `RESEARCH_FRAMING.md`：研究定位。问题、假设、与 prior art 的边界、可声称与不可声称、为什么还值得做，
  以及 STOP-01 / STOP-02 成立时项目产出什么。写论文或答辩时引这份。
- `PAPER_OUTLINE.md`：论文提纲。七节结构、关键词、相关工作、方法对应的软硬件资产、实验安排，以及一份
  待填的图表清单。
- 后续的专利披露草稿、技术报告按同一口径追加，标题、目标出处、时间、涉及的原型级别和数据来源都要记。

数据一律引用 `08_DATA/`，图引用 `09_PLOTS/`，不在这里另存一份。对外提交前把涉及安全互锁的具体接法从
公开版本里拿掉（`03_CAD/electronics/` 与架构 §6.6 的内容不披露）。§26 末尾那条 2026 年的边界切换工作与
MST-01D 很接近，涉及 D 版的说法要收着写，见 `01_PRIOR_ART/SOURCE_DIGEST.md` 的 SRC-04。

## 两份文档的关系

`RESEARCH_FRAMING.md` 是定位层，定口径：问题怎么问、假设怎么拆、贡献能说到什么程度、失败怎么表述。
`PAPER_OUTLINE.md` 是交付层，把定位层翻译成论文结构，并列出待填的图表与它们的数据来源。前者给后者提供
措辞和边界，两者对同一件事的说法必须一致。论文的相关工作一节直接引 `01_PRIOR_ART/CLAIM_MATRIX.md`，
不另起一套编号。

## 模型结论与待实验确认

目前的批次里，能写进材料的结论分两类，写作时不要混。

模型结论（来自 `04_SIMULATION/`，全部待实验确认）：

- 单级与普通膜片。同一力曲线下，A 版膜片峰值速度约 0.47 m/s，B 版约 8.9 m/s，差约 19 倍，触发力约
  1.7 N。按这个结果，STOP-01 在模型里没有被触发。出处 `04_SIMULATION/README.md` 与
  `04_SIMULATION/results/transient_summary.csv`。
- 双级与单级。名义参数下 C 版峰值速度约 10.6 m/s，比 B 版高约 18%，输入功从 20 mJ 升到 38 mJ，
  事件顺序不稳定（两级相同时第二级先触发，间隔约 4 到 7 ms；第二级刚度高 1.5 倍以上时顺序翻转）。
  模型倾向支持 STOP-02，即回退单级。出处同上与 `results/sweep_mismatch.csv`。
- 膜片柔度。峰值速度对柔度不是单调，太硬的膜把速度压到约 3.3 m/s，名义刚度到 3 倍之间有一片最佳区。
  模型没有气动侧，判断不了空气脉冲效率。出处 `results/sweep_membrane.csv`。

待实验确认（目前没有实测数据）：A1 到 E1 的全部曲线与重复性、低量程压力波形（模型不含气腔）、循环寿命
漂移、供给盘索引可靠性、边界状态的映射是否可复现。实验计划在 `07_EXPERIMENTS/TEST_PLAN.md`，数据尚未
产出，`PAPER_OUTLINE.md` 第 5 节因此是待填清单。

## 离线结论的边界

本项目在离线条件下不能得出"具有全球专利新颖性"（§25.2、§28）。prior-art 台账只有 14 条来源，结论强度
上限是"这 14 条里未发现完全同构的单一来源"。对外材料按 §28 的两张清单写：可以说候选研究贡献、本离线
资料未包含完全同构单一来源、需要后续专利检索确认、系统级组合待验证；不可以说全球首创、从未有人做过、
具有确定专利新颖性、可直接申请专利且一定通过。展开见 `RESEARCH_FRAMING.md` 第 4 节与
`01_PRIOR_ART/CLAIM_MATRIX.md` 的表述纪律一节。
