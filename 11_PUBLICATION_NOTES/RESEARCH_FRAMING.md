# MST-01 研究定位说明

这份文件把 MST-01 的研究问题、研究假设以及与既有工作的边界写清楚，供写论文、做答辩或对外说明时直接引用。
依据是主规格 `00_MASTER_SPEC/MST-01_Offline_Agent_Master_Spec_v2.0.md`（下称规格书）的 §24、§25、§27、
§28、§29、§35、§38，以及 `01_PRIOR_ART/` 下的三份台账。文中每条判断都能回溯到章节号或仓库里的某个文件，
没有实验数据的部分标"待实验确认"。

有一条前提要先讲。本项目的 prior-art 结论全部来自离线资料，规模是 8 篇论文加 6 项专利。离线资料查不到
完全同构的来源，不等于世上没有。§25.2 和 §28 对这一点有明确规定，本文第 4 节照录，写论文时也要照这个口径。

## 1. 研究问题

规格书 §24 明确要求，研究问题不要写成"我们发明了一种新的炮"。它给的正确表述是：

> 研究紧凑串联弹性失稳机构与膜片负载耦合后，边界状态、级间非线性和膜片柔度如何共同影响瞬态机械脉冲的形成。

这个问题问的是耦合规律，主语是"边界状态、级间非线性、膜片柔度"这三个量，落点是"瞬态机械脉冲的形成"。
装置本身是这个问题的实验平台。§25.2 给了更贴近实验的版本：

> 一个低成本、微型、直接机械耦合的多级失稳 / 膜片负载系统，在不同边界状态下是否能够产生可重复、
> 可选择的瞬态脉冲时间历程。

两句放一起看：前一句是力学问题，后一句是系统可实现性问题。写论文时，问题陈述用前一句，可实现的判据用后一句。

## 2. 研究假设

规格书 §35 把唯一需要用实验回答的问题写成一条假设：

> 当一个紧凑串联非线性弹性机构直接耦合到一个柔性膜片负载时，单元数量、边界状态、预载和膜片柔度
> 是否可以产生稳定、可重复、可区分的瞬态脉冲时间历程；这种响应是否相较普通直接驱动或单级 snap
> 有实际工程价值？

§35 同时注明，这是研究假设，不是专利声明。下面把假设拆开，说清每个可变项和每个观测量对应到哪一步实验。

### 2.1 可变项

单元数量。规格书 §13 用 A/B/C 三级对应 0 个、1 个、2 个失稳单元：A 是低速执行器直推膜片的基线，
B 是单级 snap，C 是双级串联 snap。§5.3 和 §14 要求先做 A → B → C 对照，不能跳级，也不能预设两级一定
优于一级。C 级 CAD 见 `03_CAD/MST-01C/`，仿真装配见 `04_SIMULATION/models/params.py` 的
`build_A` / `build_B` / `build_C`。单元数量对输出的独立贡献，是整个假设里最需要数据、也最可能被证伪的一项。

边界状态。指支撑在 fixed / locked / released 之间改变。规格书 §5.4 把它定位为研究变量，§13 的 D 版专门
验证它。D 版 CAD 目录 `03_CAD/MST-01D/` 目前还是占位。这条可变项的机制本身已有 prior art（SRC-04），
本项目要测的是边界状态到脉冲时间历程的映射是否可重复，不涉及机制的新颖性。

预载。规格书 §15.1 要求记录 preload state，§23.3 把 preload 列为优先扫描变量。仿真侧见
`04_SIMULATION/results/sweep_preload.csv`，实验侧按 `07_EXPERIMENTS/TEST_PLAN.md` 的 A1/B1 记录变量采集。
预载怎么由机械实现，在 B/C 的释放卡榫方案里定，见 `03_CAD/lib/release.py`。

膜片柔度。§6.2 给了三类候选材料，第一轮要求至少比较一种弹性体膜和一种聚酯膜。仿真里用
`04_SIMULATION/models/membrane.py` 的 Föppl 薄膜模型，扫描见 `04_SIMULATION/results/sweep_membrane.csv`。
硅胶的粘弹滞后没有建模，膜片材料常数也全是量级估计，标"待实测标定"。

### 2.2 观测量

假设里的"稳定、可重复、可区分"是三个不同的量，要分别定义。

稳定。同一个状态下反复动作，事件时刻和脉冲波形的散布有限。实验口径见 `07_EXPERIMENTS/TEST_PLAN.md`
第 0.3 节：相对标准差是样本标准差除以均值，默认每个条件至少 10 次有效动作。

可重复。换一天、重装膜片、重装弹性件之后，同一个结论还能复现。A1 的重复性基线口径是峰值位移与压力峰值
相对标准差不超过 10%。这个数字是 `TEST_PLAN.md` 新加的可执行口径，拿到 A1 数据后可以再调。

可区分。不同单元数量或不同边界状态之间，输出要有超出散布的差异。C1 要求两个 snap 事件在不少于 90%
的有效动作中可分辨且顺序固定；D1 建议以均值差超过合并标准差为判据。这些同样是 `TEST_PLAN.md` 新增的
量化口径，规格书只给了判定方向。

瞬态脉冲时间历程本身指 §15.2 的一组输出：force-displacement curve、Stage 1 / Stage 2 event time、
membrane displacement-time、low-range pressure-time、recovery time、repeatability、fatigue drift。
论文里报告这一组，不要只挑好看的一两个。

假设末半句"相较普通直接驱动或单级 snap 有实际工程价值"对应 §30 的 STOP-01 和 STOP-02。判定方向和量化
门槛见第 6 节。

## 3. 与 prior art 的边界

§2.2 和 §38 已经把结论冻结：串联 snap-through 加可切换边界本身不能作为新颖性核心。§25.1 和 §27 列了
清单，下面按技术元素归纳，证据编号沿用 `01_PRIOR_ART/SOURCE_DIGEST.md`。

已有多年的部分：

| 技术元素 | 代表证据 | 约束类型 |
|---|---|---|
| bistable mechanism，含微尺度实现 | PAT-06 | 封死子元素 |
| sequential snap、多阶段力—位移曲线 | SRC-01、SRC-02 | 直接封死 |
| 可调能量景观下的 sequential snapping 分岔 | SRC-03 | 直接封死 |
| 串联 2 到 4 单元的可编程多阶段响应 | SRC-04 | 直接封死 |
| locked / released 支撑改变边界刚度 | SRC-04 | 直接封死 |
| snap-through 驱动流体脉冲 | SRC-05 | 直接封死 |
| 双稳软膜作气动开关 | SRC-06 | 封死子元素 |
| 膜片 snap 产生短空气脉冲，工作点可调 | PAT-01 | 直接封死 |
| 失稳式空气脉冲推动软质载荷 | PAT-02 | 直接封死 |
| 单体柔顺发射器与尺度规律 | SRC-07 | 封死子元素 |
| 双稳态弹射小物体 | SRC-08 | 封死子元素 |
| 气动加旋转索引供给 | PAT-03 | 封死工程实现 |
| 电机旋转软载荷弹仓 | PAT-04 | 封死工程实现 |
| 软弹加弹仓供给 | PAT-05 | 封死工程实现 |

展开版在 `01_PRIOR_ART/CLAIM_MATRIX.md`，那张表比这里多了"具体被覆盖的是什么""还剩下什么没被覆盖"
两列，写论文的相关工作一节可以直接引。

本项目能提的贡献只剩三个点，全部落在矩阵末三行：

1. 多级失稳与被动膜片负载的特定瞬态耦合规律。离线资料里多级失稳和流体脉冲各有来源，把多级非线性核心
   直接机械耦合到被动柔性膜片这一具体组合，没有找到完全同构的单一来源。缺口在耦合这一层，静态力—位移
   曲线回答不了。
2. 小型系统中不同边界状态对输出脉冲时间历程的可重复映射。邻近证据很多，风险中高。关键词落在可重复上，
   可调部分已经有 SRC-03 和 SRC-04 覆盖。
3. 具体结构细节形成的新组合。这条现在无法评估，结构还没冻结。要等定型后做 claim-level 检索，按具体构造
   查，不按机制名称查。

这三点都标"候选研究贡献"或"待验证"。不要把第 1 点的"没找到同构来源"写成"没人做过"，也不要把第 2 点的
映射写成已经成立的结论。第 3 点在没有检索之前什么都别说。

## 4. 可声称与不可声称

§28 把两张清单写死了，这里照原样列出。

可以说：

- 候选研究贡献；
- 本离线资料未包含完全同构单一来源；
- 需要后续专利检索确认；
- 系统级组合待验证。

不可以说：

- 全球首创；
- 从未有人做过；
- 具有确定专利新颖性；
- 可直接申请专利且一定通过。

为什么这个纪律重要。离线台账只有 14 条来源，它的结论强度上限就是"这 14 条里没找到同构来源"，§25.2
已经写明不能在离线状态下得出"具有全球专利新颖性"。把上限当成结论写进论文或专利披露，评审或审查时会
直接崩，还会连带把本来站得住的研究贡献一起拖下水。按清单的口径写，即使 novelty 最终不足，力—位移与
动态脉冲数据、缩放研究、可复现平台这几项产出仍然成立（§29）。`01_PRIOR_ART/CLAIM_MATRIX.md` 的
"表述纪律"一节也照录了同样的清单。

## 5. 为什么仍然值得做

§29 把问题从"发明一个没人见过的发射器"改成：

> 研究一个微型低成本非线性机械脉冲核心在被动膜片负载下的瞬态耦合规律，并把它做成可模块化、
> MCU 管理的实验平台。

这么改之后，prior art 密度高不再是要不要做的决定因素。§29 列了可能得到的五类产出：一个可工作的工程
装置；一套力—位移与动态脉冲数据；一个缩放研究；一个可复现实验平台；若具体结构组合确有差异，再进入
正式 claim-level 查新。

到目前的进度：工程装置和模型已经在仓库里。A/B/C 三级 CAD 有参数化几何与 STL 导出（`03_CAD/`），
释放门控板有原理图、板图和验证步骤（`03_CAD/electronics/`），固件与双区域状态机在 `05_FIRMWARE/`，
数值模型在 `04_SIMULATION/`。实验数据还没有，`07_EXPERIMENTS/` 目前只有计划。所以现在能写的是方法、
模型和待填结果，不能写实测结论。

## 6. 失败也有价值的情形

§30 定了 STOP 条件，`07_EXPERIMENTS/TEST_PLAN.md` 把它们落到具体实验和记录位置。这里说两种失败，
它们都不否定项目。

STOP-01：单级 snap 相比普通膜片没有可测优势。触发点是 B1。按 TEST_PLAN 的口径，如果相对 A1 膜片到达
峰值位移的时间中位数改善低于 20%，且压力上升时间没有明显缩短，就算没有可测优势，这时停止双级研究。

项目产出什么：A1 的基线数据、B1 的阴性结果，以及一条关于"在这个尺度和力级下，单级失稳是否值得引入"
的有界结论。B1 的模板、测量链和重复性口径都已经建好，结论可复现。表述上写成阴性结果，说明在给定参数
区间里没测到优势，不要写成"snap-through 对空气脉冲无效"这种一般化断言。边界限定在名义参数和这套模型，
超出这个区间要另测。

STOP-02：双级比单级明显更差。触发点是 C1。更不稳定、响应没有区别、寿命下降严重，三条占一条就可能触发，
回退单级。

项目产出什么：A/B/C 三级的对照数据本身就是结果，能说明多加一级非线性在这个尺度上换来的是复杂度而不是
输出，输入功还涨了。表述上限定在名义参数，比如当前仿真显示 C 版峰值速度只比 B 版高约 18%，输入功从
20 mJ 升到 38 mJ。这是模型输出，待 B1/C1 实验确认。

补一句，STOP-03（边界切换没有稳定可复现差异）的处置类似，D 版不进入论文主线，记录并关闭边界研究分支，
见 TEST_PLAN 的 STOP 对照表。两种失败记录都进 `10_FAILURE_ANALYSIS/`，被放弃的机构和对应实验要写清楚，
不要只删代码和目录。

有一个和失败相关的现状要交代：`04_SIMULATION/README.md` 基于名义参数的初步结论目前倾向支持 STOP-02，
即回退单级；STOP-01 在模型里没有被触发（B 版膜片峰值速度约为 A 版的 19 倍）。这两条都是模型结论，
不是实测，必须由 §16 的 A1/B1/C1 实验确认。
