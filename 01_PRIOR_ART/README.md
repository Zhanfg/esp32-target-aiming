# 01_PRIOR_ART

现有文献与专利的梳理，规格书 §26 那份列表是起点：SRC-01 到 SRC-08 是论文，PAT-01 到 PAT-06 是专利，
每条都带来源编号，后续引用沿用这些编号。

按 §20 这个目录下放三份文件：

- `SOURCE_DIGEST.md`：逐条摘要，只留与两级串联失稳、边界可切换、软载荷发射相关的内容。
- `CLAIM_MATRIX.md`：规格书 §27 的矩阵，把来源按机制、边界条件、驱动方式、是否可逆几个维度铺开，
  用来判断哪些做法已经被公开过。
- `VERSION_CORRECTIONS.md`：来源里的年份、作者、专利号如有出入，记在这里并写清楚依据。

§25 划了当前 IP 的边界，读文献时对照那份清单，别把已有公开内容当成自己的点。§26 末尾提到
2026 年已出现很接近的边界切换概念，D 版因此只算科研变量。
