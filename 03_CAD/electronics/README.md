# MST-01 释放门控电路板（release-gate）

本目录是释放路径的硬件门控板。它把统一架构方案 §6.6 的与门树、§6.5 的 H1/H2/H3/H4/H6
做成实体电路，让固件即使卡死或输出错误电平，也放不出一次释放。对应主规格 §10.3 的
`RELEASE_CMD` 输出与 §11 的四条互锁。

架构 §6.11 第一条说得很直接：这条不通过，后面所有状态机都是纸面。所以本板的设计重点不在
控制精度，而在每一个输入的失效方向，以及一块被卡住的 MCU 能造成什么。

信号极性和接口以 `02_REQUIREMENTS/interfaces.md` 第 5 节为准，引脚沿用
`05_FIRMWARE/include/config.h` 的 `RELEASE_CMD_PIN`、`STAGE1_STATE_PIN`、`STAGE2_STATE_PIN`
等定义。两者不一致时以接口文档为准，本板按接口文档的电平做。

## 2. 供电与地

板上有两条供电，进板后各自串自恢复保险丝和防反：

- 逻辑轨 `+3V3`：从主控逻辑电源引入，经 `D14`（SS14 防反）与 `F1`（MF-MSMF050）。
  供五片 74HC、上拉/下拉和继电器（本版无继电器）。
- 执行轨 `V_ACT_IN`：从舵机与执行器电源引入，先过 `J7` 上的急停常闭触点变成 `V_ACT_SW`，
  再经 `F2`（MF-MSMF200）到释放电磁铁，另经 `F3`（MF-MSMF110）到预载执行器。
- 单点共地。逻辑地与执行地在板上汇到同一块铺铜，不另做隔离，避免地环路。

急停之后才出现 `V_ACT_SW`，这一点让急停独立于任何逻辑元件。后面所有 MOS 开关都只能
在 `V_ACT_SW` 存在时给执行器供电。

## 3. 与门树

### 3.1 逻辑表达式

```
Q1 = FIRE_INHIBIT_N · EXTERNAL_ALLOW · MECH_RECOVERED_N · POCKET_OR_MODE_A
Q2 = Q1 · ARMED_LATCH · RELEASE_PULSE · MASTER_ENABLE_GATED
MASTER_ENABLE_GATED = MASTER_ENABLE_RAW · FAULT_OK
FAULT_OK            = NOT(FAULT_LATCH)
POCKET_OR_MODE_A    = POCKET_ALIGNED OR MODE_A_RAW
```

Q2 经 `R22` 驱动低边 MOSFET `M1` 的栅极。M1 导通，释放电磁铁才通电；Q2 为低或悬空时 M1
关断。整条链上任何一级为假，释放都不可能发生。

### 3.2 器件选择

工程实践里做四输入与门，直接用一片 74HC21 最省。74HC21 是双 4 输入与门，一片正好给出
Q1 和 Q2 两级，不需要用 74HC08 拼树，也不用二极管与门凑，输入数、门数、传播延迟都对得上。
逻辑轨 3.3V，74HC 系列在 3.3V 下的输入阈值和驱动能力都够用。

其余逻辑按功能配：

- `U2` 74HC123：双可重触发单稳态，一半做释放脉宽钳位，一半做归零复位脉冲。
- `U3` 74HC74：双 D 触发器，一半做故障锁存，一半做武装锁存，异步置位/复位正好用来接
  故障置位和归零复位。
- `U4` 74HC11：三 3 输入与门，做三处 HOME 的与、武装时钟门、取消武装逻辑。
- `U5` 74HC14：六施密特反相器，做极性取反和慢边沿整形。
- `U6` 74HC08：四 2 输入与门，把故障锁存输出接进主使能和预载使能。

### 3.3 输入极性与开路行为

每个输入都按“开路即禁止”配偏置。外部上拉或下拉只是并上去，板端自己的偏置保证接插件
松脱、断线、掉电时落到禁止侧。执行器电源上的急停触点另算，它断的是功率。

| 信号 | 有效方向 | 板端偏置 | 开路结果 | 落点 |
|---|---|---|---|---|
| `FIRE_INHIBIT_N` | 高 = 未否决 | `R1` 10k 下拉，`R2` 串联 10k，`C1` 100n | 拉到低 | 否决，Q1 为假 |
| `EXTERNAL_ALLOW` | 高 = 许可 | `R3` 10k 下拉，`R4` 串联 10k，`C2` 100n | 拉到低 | 拒绝，Q1 为假 |
| `MECH_RECOVERED_RAW` | 低 = 机构已复位 | `R7` 10k 上拉，`C4` 100n | 拉到高 | 经 `U5A` 反相为低，Q1 为假 |
| `POCKET_ALIGNED` | 高 = 载荷对齐 | `R5` 10k 下拉，`R6` 串联 10k，`C3` 100n | 拉到低 | 对齐不满足，Q1 为假 |
| `MODE_A_RAW` | 高 = 模式 A 旁路 | 经 `JP1` 与外部常闭触点，`R27` 100k 下拉 | 拉到低 | 撤销旁路，退回要求真实对齐 |
| `ARM_CMD` | 高 = 请求武装 | `R8` 10k 下拉，`C5` 100n | 拉到低 | 不武装 |
| `DISARM_CMD` | 高 = 取消武装 | `R9` 10k 下拉，`C6` 100n | 拉到低 | 不取消，见 3.4 |
| `FAULT_CMD` | 高 = 软件请求故障 | `R10` 10k 下拉，`C7` 100n | 拉到低 | 不置故障，见 3.4 |
| `MCU_RELEASE_CMD` | 高 = 释放请求 | `R12` 10k 下拉，`R11` 串联 1k，`C8` 100n | 拉到低 | 无请求 |
| `MASTER_ENABLE_RAW` | 高 = 主使能有效 | `R18` 10k 下拉，`C13` 100n，且串急停触点 | 拉到低 | Q2 为假 |
| `PAN_HOME` / `TILT_HOME` / `MAG_HOME` | 高 = 已触发 | `R15` / `R16` / `R17` 10k 下拉，`C10` 到 `C12` 100n | 拉到低 | 视为未归零，故障锁存不能复位 |

`FIRE_INHIBIT_N` 与 `EXTERNAL_ALLOW` 的静态偏置在接口文档里规定为外部 10k 下拉，板端再各
并一只下拉，断线时两处都往低走。

### 3.4 两处不落到禁止侧但可接受的开路

`FAULT_CMD` 与 `DISARM_CMD` 开路时都拉到低。低电平分别表示“不置故障”和“不取消武装”。
两者都不是禁止侧电平，但它们本身只是软件发起的动作请求，缺失不会让释放更容易发生：
置故障是让系统更安全，取消武装也只是把武装锁存清零。真正的拦截已经由
`FIRE_INHIBIT_N`、`EXTERNAL_ALLOW`、`MASTER_ENABLE_RAW` 和故障锁存承担。这里如实标出，
免得把“开路即禁止”一概而论。

## 4. 单稳态钳时

### 4.1 电路

`MCU_RELEASE_CMD` 从 `J3` 进来，串 `R11`、对地 `C8`，接到 `U2A` 的 B 触发端（引脚 2）。
`U2A` 的 A 端（引脚 1）接 `GND`，使上升沿触发；`CLR`（引脚 3）接 `+3V3`。输出 Q（引脚 4）
是 `RELEASE_PULSE`，接到 Q2 的一个输入。RC 定时网络是 `R19` 与 `C15`，分别接在
`1REXT`（引脚 7）与 `1CEXT`（引脚 6）。

GPIO 直连的长驱动不再存在，释放命令必须先过这一级。MCU 把 `RELEASE_CMD` 拉高并保持，
单稳只输出一个固定宽度的脉冲，之后回到低，不会持续通电。

### 4.2 脉宽计算

74HC123 的脉宽按数据手册：

```
t_W ≈ K · R_EXT · C_EXT
```

其中 `K` 在 `C_EXT ≥ 1000 pF`、`VCC = 3.3V` 附近典型值约 1.0。取

- `R19 = 33 kΩ`，`C15 = 1 µF`，得 `t_W ≈ 33 ms`。

固件侧的软件脉宽是 `RELEASE_PULSE_MS = 30 ms`。硬件上限略大于软件脉冲，正常工作时由软件
结束释放，硬件不截断；MCU 卡在输出高时，硬件在约 33 ms 后强制关断。两侧都留了容差，实际
脉宽受电容容差（约 ±10%）、电阻容差和 `K` 的温度漂移影响，台架上用示波器测 `RELEASE_PULSE`
实测宽度，按结果微调 `C15`。执行器若需要更长动作时间，加大 `C15` 后重新验证。

`U2B` 用同样的公式做归零复位脉冲：`R20 = 22 kΩ`，`C16 = 1 µF`，得约 22 ms。

单稳是可重触发的。MCU 卡高只给一个上升沿，所以是一个脉冲；固件在释放脉冲有效期内不得
再次翻转 `RELEASE_CMD`，否则会把脉冲续长，这一条写进固件约束。

## 5. 负载开关

释放电磁铁的回流路径上串低边 N 沟道 MOSFET `M1`（AO3400A，SOT-23）：

- 栅极由 `Q2_OUT` 经 `R22`（100Ω）驱动，栅源之间有 `R21`（100k）下拉。Q2 悬空或走线断开时
  `R21` 把栅极拉到 `GND`，M1 关断。
- 漏极接 `EMAG_LO`（电磁铁回流端），源极接 `GND`。
- 电磁铁两端反并 `D1`（SS34），阴极朝 `EMAG_HI`，关断瞬间给感性电流一条续流回路。
- `V_ACT_SW` 到 `EMAG_HI` 之间串 `F2`（MF-MSMF200 自恢复保险丝），短路或堵转时限流。
- `V_ACT_SW` 对地挂 `D13`（SMBJ16A）做瞬态钳位。

预载执行器走同样结构：`M2` 栅极由 `PRELOAD_ENABLE` 驱动并带 `R23` 下拉，漏极 `PRELOAD_RET`
接 `J4` 的 2 脚。它的源极在板上不直接接地，改从 `J4` 的 3 脚 `MECH_RET` 引出，装机时把
机构常闭触点串进去再回地。机构未复位，触点断开，预载执行器在物理上没有回流路径。

## 6. 故障锁存器

### 6.1 电路

故障锁存用 `U3A`（74HC74 的一半）：

- 置位 `/1S`（引脚 4）接 `FAULT_SET_N`，由 `R29` 上拉，被 `U5E`（`FAULT_CMD` 反相）或
  急停辅助触点（`J7` 的 5、6 脚，常开对地）拉低时置位。
- 复位 `/1R`（引脚 1）接 `FAULT_RESET_N`，由 `R30` 上拉，被 `U2B` 的 `/Q`（引脚 13）
  或上电复位网络拉低时清零。
- 输出 `Q`（引脚 5）是 `FAULT_LATCH`，高表示故障已锁存并且保持。

`FAULT_LATCH` 经 `U5B` 取反成 `FAULT_OK`。`FAULT_OK` 进 `U6A`，与 `MASTER_ENABLE_RAW` 相与
得到 `MASTER_ENABLE_GATED`，作为 Q2 的一个输入；同时进 `U6B`、`U6D`，与 `PRELOAD_CMD`、
`MECH_RECOVERED_N` 相与得到 `PRELOAD_ENABLE`。故障一旦锁存，主使能被切断，预载也使能被切断。

### 6.2 为什么必须重新归零由电路保证

复位脉冲不是简单地把三处 HOME 相与。三处 HOME 先进 `U4A` 得到 `HOME_AND`，再送 `U2B` 的
B 端。`U2B` 只在 `HOME_AND` 的上升沿触发一次，输出一个约 22 ms 的低脉冲去清零 `U3A`。

这样处理有两个后果。机构停在非零位时 `HOME_AND` 为低，故障清不掉；要把三轴都驱动到参考
开关并同时触发，才会出现一次上升沿。如果故障发生时机构恰好已经停在三处零位，`HOME_AND`
没有边沿，锁存同样清不掉，必须先离开零位再重新归零。复位只发生在物理归零完成的瞬间，
软件无法凭一个 GPIO 把锁存清掉。

上电复位由 `R28`、`C14` 产生 `POR_N`，通过 `D11`、`D12` 分别接 `FAULT_RESET_N` 与
`ARM_RESET_N`，保证上电时两个锁存都从清零态开始，直到第一次真实归零。

## 7. 急停

急停用常闭蘑菇头，三个触点全部走 `J7`，不经过 MCU：

- 触点一（`J7` 1、2 脚）：串在执行轨里，`V_ACT_IN` 与 `V_ACT_SW` 之间。按下就断开执行轨，
  释放电磁铁和预载执行器同时失去供电。这条对应 H6。
- 触点二（`J7` 3、4 脚）：串在 `MASTER_KEY` 与 `MASTER_ENABLE_RAW` 之间。按下就让 Q2 的
  主使能输入变低。
- 触点三（`J7` 5、6 脚）：常开对地，按下时把 `FAULT_SET_N` 拉低，故障锁存置位。

按一次急停，执行轨断电、主使能断开、故障锁存置位三件事同时发生，而且都不依赖固件。

## 8. 模式 A 旁路

供给盘相关的对齐信号在模式 A 用旁路成真。旁路用外部常闭触点加焊接跳线 `JP1` 实现，
不靠继电器吸合直接给信号：

- `J6` 提供 `+3V3`（1 脚）、`MODE_A_SW`（2 脚）、`GND`（3 脚）。装机时把供给盘不在位时
  闭合的常闭触点接在 1、2 脚之间。
- `MODE_A_SW` 经 `JP1` 到 `MODE_A_RAW`，再由 `D7` 与 `POCKET_ALIGNED`（经 `D8`）做二极管或，
  节点 `POCKET_OR_MODE_A` 用 `R26` 100k 下拉后进 Q1。
- 供给盘没装时触点闭合，`MODE_A_RAW` 被拉高，旁路成立，模式 A 可以动作。装上盘后触点断开，
  `R27` 把 `MODE_A_RAW` 拉到低，旁路撤销，必须 `POCKET_ALIGNED` 为高才放行。默认状态落在
  模式 A 无载荷这一侧，符合架构 §6.5 的 H3。

需要跑模式 B 时把 `JP1` 拔掉，旁路彻底失效，只认对齐传感器。这一步写进模式 B 的作业流程。
另外要说明，如果供给盘实际已装但常闭触点卡在闭合，旁路会误成立，属于单点失效，见第 11 节。

## 9. ARMED_LATCH

`ARMED_LATCH` 由硬件锁存给出，用 `U3B`（74HC74 的另一半），不是 MCU 的普通 GPIO。

理由是架构 §6.9 第 8 条已经指出纯软件武装是缺陷。若武装只由一个 GPIO 表示，卡住的 MCU
可以直接把它拉高，与门树就少了一道。做成硬件锁存后，武装有三个条件同时满足才会成立：

```
ARM_CLK = Q1_OUT · ARM_CMD        （U4B 输出）
```

`ARM_CLK` 接到 `U3B` 的时钟端（引脚 11），`D` 端（引脚 12）接 `+3V3`，所以时钟上升沿把
`ARMED_LATCH` 置高并保持。要出现这个上升沿，`Q1_OUT` 必须已经为真，也就是外部许可、
安全否决、机构复位、对齐这几路全部成立，同时 MCU 给一次 `ARM_CMD`。MCU 单独把 `ARM_CMD`
钉在高不会重复置位，因为 `U3B` 是边沿触发。

清零走 `ARM_RESET_N`（`U4C` 输出）：

```
ARM_RESET_N = FAULT_OK · REL_IDLE · DISARM_CMD_OK
REL_IDLE    = NOT(RELEASE_PULSE)
```

故障锁存置位、一次释放脉冲结束、或 MCU 给 `DISARM_CMD`，都会把武装锁存清掉。这样一次
武装对应一次释放，发完自动回到未武装。上电由 `D12` 把 `ARM_RESET_N` 拉低清零。

## 10. H1 到 H6 的落点

| 硬约束 | 在本板上的落点 |
|---|---|
| H1 释放能量路径受多重条件约束 | `U1`（74HC21）构成 Q1 与 Q2 两级与门；`U2A` 把释放命令钳成单脉冲；`M1` 低边开关串回流路径；`F2` 限流；急停触点串执行轨。Q2 为假时 M1 关断 |
| H2 机构未复位时预载无法驱动 | `M2` 源极不接板地，经 `J4` 3 脚引到机构常闭触点再回地，触点断开时物理断路；逻辑上再经 `U6B`、`U6D` 与 `MECH_RECOVERED_N` 相与 |
| H3 模式 B 未对齐时释放无法完成 | `POCKET_ALIGNED` 经 `D8` 进 Q1；模式 A 由 `J6` 常闭触点加 `JP1`、`D7` 旁路，默认落在无载荷一侧 |
| H4 故障与急停锁存，未重新归零不能复位 | `U3A` 故障锁存；复位由 `U2B` 对 `HOME_AND` 上升沿的单稳脉冲驱动；锁存输出经 `U6A`、`U6B` 切主使能与预载 |
| H5 超出机械限位 | 本板不承担，由结构件物理止挡实现 |
| H6 主电源急停 | `J7` 的常闭触点直接串 `V_ACT` 与主使能键路，不经 MCU；辅助触点置故障锁存 |

## 11. 单点失效分析

下面列出会导致误释放的元件失效。误释放指在没有满足全部许可条件、或 MCU 不该发出释放时，
释放电磁铁仍被通电。

| 失效元件 | 失效方式 | 后果 | 板上是否有冗余或缓解 |
|---|---|---|---|
| `U2A`（74HC123） | 输出对 `+3V3` 短路或内部失效使 Q 恒高 | 时间钳位失效，只要 Q1、`ARMED_LATCH`、主使能成立就持续通电 | 无。缓解只能靠急停，建议改版加第二把串联器件或双单稳 |
| `M1`（AO3400A） | 漏源短路 | 不依赖栅极，`V_ACT_SW` 存在时电磁铁就通电 | 急停常闭触点串在 `V_ACT_SW` 之前，可断电；`F2` 只限流不切断 |
| `MOS_GATE_RELEASE` 走线 | 短到 `+3V3` | 绕过 Q2 使 M1 恒导通 | 急停可断电；建议改版在栅极串第二只受主使能控制的器件 |
| `U6A`（74HC08） | 输出卡高 | `MASTER_ENABLE_GATED` 恒高，故障锁存切不断主使能 | 无自动缓解，只能重新上电走 POR |
| `U5B`（74HC14） | 输出卡高使 `FAULT_OK` 恒高 | 故障切不断主使能与预载 | 无自动缓解 |
| `FIRE_INHIBIT_N` 线 | 短到 `+3V3` | 安全否决失效（对应 FM-08） | 板上无。需要架构 §6.7 提的双冗余触点交叉校验，本版留了位置未做 |
| `POCKET_ALIGNED` 线 | 短到 `+3V3` | 对齐失效，模式 B 可放出未对齐载荷 | 拔掉 `JP1` 不能阻止这一个，仍需双通道 |
| `MECH_RECOVERED_RAW` 线 | 短到 `GND` | 被当成已复位，Q1 与预载逻辑都放行 | 无。断线方向是安全的，短到地是危险方向 |
| `EXTERNAL_ALLOW` 线 | 短到 `+3V3` | 伪许可 | 无，需双通道 |
| `JP1` 与供给盘触点 | 盘已装但触点卡在闭合 | 模式 B 下旁路对齐 | 模式 B 流程要求拔掉 `JP1`，可消除这一条 |
| `U4C`（74HC11） | 输出卡高使 `ARM_RESET_N` 恒高 | 故障后武装锁存清不掉，只能上电复位 | 不影响误释放，但削弱互锁，建议改版用两把器件 |

不会导致误释放的失效方向也列出，说明哪些地方失效是安全的：`U3B` 失电或卡低使武装不成立；
`U5A` 失效使 `MECH_RECOVERED_N` 为低；`U5C` 卡高使 `REL_IDLE` 为高只是不能清零武装；任一
输入下拉丢失让对应条件不成立。这些方向都落到不释放。

冗余现状：急停有两个独立触点分别断执行轨和断主使能，这一点是冗余的。故障复位要求物理
归零序列，不能由单个信号清掉。架构 §6.7 与 §6.6 提到的双通道冗余触点交叉校验、安全输入
短路到 3V3 的检出，本版没有实现，是本板需要补的最大缺口。安全完整性做到哪一级要由后续
试验确认，设计上先按双通道留位。

## 14. 已知缺口与下一步

1. 双通道冗余触点与安全输入短路到 3V3 的检出尚未实现。这是 FM-08 与 §6.7 的缺口，也是
   本板最该先补的部分。
2. 信号布线已自动布通大半，但未干净。用 Freerouting 2.4.1（JAR 在 `~/.kicad-mcp/freerouting.jar`）
   自动布线，未连接项从 151 降到 23。管线是：`pcbnew.ExportSpecctraDSN` 导出 DSN、
   `java -jar freerouting.jar -de <dsn> -do <ses> --gui.enabled=false -mp 30` 布线、
   `pcbnew.ImportSpecctraSES` 回导、`pcbnew.ZONE_FILLER` 重灌铜箔。**重灌那一步不能省**，
   否则铜箔没避让新走线，DRC 会把 511 处报成短路。

   两个残留问题。一是线宽：DSN 里的规则写的是 `(width 200)`（0.2 mm），工程 netclass 也是 0.2 mm，
   但 Freerouting 实际用了 0.15 mm，留下 19 条线宽违规。二是 23 个未连接项，Freerouting 只报 2 条
   布不通，其余应该是重灌铜箔后不再靠铺铜糊住的连接。正式投板前这两项都要清掉。
3. 执行器电流尚未冻结。`M1`、`F2`、`D1` 的规格按中小电流电磁铁选的，执行器定型后按峰值
   电流与浪涌时间复核，必要时换更大封装的 MOSFET 和保险丝。
4. 归零复位脉宽与释放脉宽都要在台架实测后微调，见 `test-procedure.md`。
5. 本板按模式 A 默认安全侧设计。模式 B 的作业流程必须包含拔除 `JP1`,否则旁路会在盘已装
   时留下误释放通道。
