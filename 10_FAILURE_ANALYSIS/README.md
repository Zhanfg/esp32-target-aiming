# 10_FAILURE_ANALYSIS

失效分析与 STOP 条件的记录。

规格书 §30 的五条 STOP 里，STOP-01（单级无可测优势）、STOP-02（双级更差）、STOP-03（边界无稳定差异）、
STOP-05（成本超 ¥50）是结论性或预算性判定，不进运行时故障，结论写在这里。STOP-04（供给盘频繁卡料）
是运行期软故障，判定与升级条件见统一架构方案 §6.8，发生记录也归到这里。

另外 §7 列了失稳单元本身的失效模式，§11 的机械安全互锁失效如果实验里真出现，按现象、复现条件、
怀疑原因、处置分条记，附上 `08_DATA/` 里的数据位置。没复现的记录不要写成结论。

确认要放弃某条路线时，把被放弃的机构和对应实验一并写清楚，别只删相关代码和目录。
