# 04_SIMULATION

仿真分三类，对应规格书 §23。

- `quasi-static/`：§23.1。至少要给出力-位移曲线、稳定分支、snap point、Stage 1 / Stage 2 的先后，
  以及边界敏感度。用来看失稳单元在什么载荷下翻过去。
- `transient/`：§23.2。关注 snap 之后的速度、两级间隔、膜片运动、结构振铃。回答的是翻得够不够快、
  够不够稳。
- `parameter-study/`：§23.3。参数不要盲目平铺，优先扫边界刚度、预载、两级失配、膜片刚度、机械阻尼
  这几项，其余固定在名义值上。

输入几何来自 `03_CAD/`，材料参数与实测对照放 `08_DATA/`。仿真结果先落到 `08_DATA/`，再出图进 `09_PLOTS/`。
准静态和瞬态用同一套几何、同一套材料常数，否则两者对不上时说不清是模型问题还是参数问题。
