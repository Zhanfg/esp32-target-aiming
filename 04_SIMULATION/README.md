# MST-01 数值仿真模型

这是规格书 §23 要求的纯软件力学模型，用 Python 与 numpy 求解，不依赖有限元软件，
也不需要 scipy。模型覆盖 §13 的 A/B/C 三个原型：A 普通膜片，B 单级 snap，
C 双级串联 snap。

模型只服务于静态与动态规律，不证明任何方案更优。§5.3 要求保留单级对照，
并允许得出「双级应被淘汰」的结论，下面的初步结论按模型实际给出的结果写。

## 模型

### 膜片

把膜片当成预张紧圆膜，夹持边界固定，中心被推杆顶出。采用 Föppl 大挠度薄膜
理论的单模态近似，挠曲形状取抛物线 w(r)=w0(1-(r/a)^2)，解轴对称面内场后积分
应变能再对中心挠度求导，得到

    F(w) = 2·π·N0·w + π·E·t·(7-ν)/(6·(1-ν)·a²) · w³

线性项来自预张力 N0=E·t·ε0/(1-ν)，三次项来自几何大挠度引起的膜内拉伸。
推导步骤写在 `models/membrane.py` 的文件头。抛物线是单模态近似，系数为量级正确，
不是椭圆积分精确解。

假设与局限：轴对称、忽略弯曲刚度、线弹性小应变、预张力与几何拉伸解耦、推杆
半径远小于膜半径。硅胶的粘弹滞后没有建模，会高估回弹能量。挠度接近半径时
误差增大。参数见 `models/params.py`。

### von Mises truss

两根斜杆加可滑动底端。势能写成

    U(h,u) = k_bar·(ℓ-L)² + k_base·u²,  ℓ=sqrt((a+u)²+h²)

给定顶点高度 h，先由 ∂U/∂u=0 解出底端张开量，再用包络定理得到顶点力。
`k_base` 就是规格书 §5.4 与 SRC-04 讨论的边界刚度：它越大越接近锁定支撑，
snap 力随边界刚度单调上升；边界太软时双稳性变弱。这一点在准静态边界敏感性
里可以直接看到。

假设与局限：杆线弹性、忽略杆弯曲与屈曲、忽略摩擦与间隙、底端弹簧线性、
对称二维运动、质量集中在顶点。`k_bar` 是把弹性片弯曲柔度折算到杆轴向的等效
参数，不是材料拉伸刚度，必须实测标定。

### 串联链与求解

A/B/C 都装配成一维串联链。瞬态用力控：外力在 20 ms 内按 smoothstep 升到目标值
后保持。用力控而不是刚性位移驱动，是为了让作动器有明确的力上限，snap 之后
不会持续注入能量。积分用速度 Verlet（kick-drift-kick）固定步长；无阻尼时它是
辛格式，能量误差随步长二阶收敛。力表用三次 Hermite 插值，避免分段线性折点在
高速运动时影响能量。

准静态用位移控牛顿法沿稳定分支前进，输入力的第一个局部极大就是 snap 阈值。
这样不依赖「牛顿失败」这种脆弱判据。到达极限点后停止跟踪。

步长选择：按最高关注频率取周期的 1/100 以下，默认 dt=1e-6 到 5e-7 s；
能量守恒测试用无阻尼自由振动核对，相对漂移在 1e-6 量级。

已知忽略项：摩擦、重力、气压反作用与流体耦合、接触碰撞的细节、膜片面内质量
分布、疲劳与塑性、面外失稳与不对称分岔、作动器自身动力学与柔度、材料粘弹。
这些是最可能让定量结论失真的地方。

## 基于模型的初步结论

这些是模型输出，不是实测结论，必须用 §16 的 A1/B1/C1 实验确认。

### STOP-01 单级 snap 相对普通膜片

同一力曲线下，A 版膜片峰值速度约 0.47 m/s，B 版约 8.9 m/s，模型里单级 snap 的
膜片速度约高 19 倍。触发力约 1.7 N，与失稳单元的 snap 力一致。按这个结果，
STOP-01 没有被触发，单级 snap 值得继续做实验。注意 A 版的 0.47 m/s 是慢推下
膜片自身的响应速度，B 版的速度来自 snap 释放，两者口径一致但含义不同。

### STOP-02 双级是否更差

名义参数（两级相同、gap 0.6 mm）下，C 版膜片峰值速度约 10.6 m/s，只比 B 版高约
18%，输入功却从 20 mJ 升到 38 mJ。事件顺序不稳定：两级相同时第二级先触发，
第一级后触发，间隔 7.21 ms；当第二级刚度比第一级高 1.5 倍以上时顺序翻转成
第一级先触发。整段失配扫描的间隔落在 2.32–4.20 ms，最大 4.20 ms 出现在刚度比
1.0 处。准静态下两级几乎同时到达
fold，静态分不出先后。

按 §30 的口径，双级更复杂、顺序不固定、输出提升有限，本模型倾向于支持 STOP-02，
即回退单级。这个判断只在名义参数与当前模型假设下成立。

### 膜片柔度

膜片刚度扫描显示，峰值输出速度对柔度不是单调：太硬的膜（刚度放大 100 倍）
把速度压到约 3.3 m/s，偏软一侧在刚度放大 0.1 倍处有一个内部低点（7.00 m/s），
之后回升，在刚度放大 0.3 倍到 3 倍之间有一片较宽的最佳区（8.74–9.05 m/s）。
模型没有气动侧，无法直接判断「太软的膜吸收 snap 输出」，只能给出机械侧速度
随柔度的变化。要判断空气脉冲效率，需要在模型里加入气腔与压力，或直接用实验
的 pressure-time 数据。

## 模型依据

- 膜片：Föppl / Hencky 大挠度薄膜理论，单模态（Galerkin）近似，推导见
  `models/membrane.py`。
- 双稳单元：经典 von Mises truss 的双稳势能，配合可滑动底端的边界弹簧；
  串联 snap 与边界刚度可调的概念来源是 SRC-04（Santos 2026），本模型只借用
  概念，不复现其结构或数据。
- 瞬态：速度 Verlet 辛积分，误差二阶收敛；步长收敛由 `solver.convergence_check`
  和测试核对。
- 没有使用 scipy，依赖只有 numpy。

## 没有来源的参数如何处理

`models/params.py` 里每个量都标注了出处或估计依据。材料模量、等效杆刚度、
质量、阻尼、gap 这些没有实测支撑的，写「量级估计，依据：…」或「待实测标定」。
绝对数值不要直接当设计输入，先做 §17 的标定实验。
