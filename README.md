# esp32-target-aiming

ESP32-S3 上的本地视觉目标锁定系统。摄像头找到目标，单片机算角度和轨迹，驱动双轴电机舵盘
把目标压回画面中心。

上位机只在开发期用，负责算法验证和标定。运行时不参与。

## 硬件

| 部件 | 选型 |
|---|---|
| 主控 | ESP32-S3 N16R8（16MB Flash / 8MB PSRAM） |
| 摄像头 | OV2640（主）/ OV5640（备） |
| 电机 ×2 | JGB37-520 12V 有刷减速电机，带霍尔编码器 |
| 驱动 | TB6612FNG 双路 H 桥，一片驱两轴 |
| 反馈 | ESP32 PCNT 硬件正交解码，四倍频 |
| 发射器 | 抽象接口 + 占位实现，型号待定 |
| 工具链 | VSCode + PlatformIO，C++17 |

## 几个设计取舍

先在 PC 上用 Python 把算法跑通再移植到单片机。参数在板子上盲调，出了问题分不清是算法错
还是传感器噪声大。

角度比较一律走 `angle_utils` 的环绕分支。现在按 ±180° 限位，将来换滑环做 360° 连续旋转时
控制算法不用重写。

提前量按执行机构滞后算。激光直瞄没有弹丸飞行时间，前视时间只由三部分组成：驱动延迟、
机械稳定时间、剩余角度除以最大角速度。

发射器需要显式 armed 且处于锁定态才允许触发，急停无条件生效。

## 安全

这套东西含电机驱动机构和发射器接口。

上电前对照实物原理图核对 `05_FIRMWARE/include/config.h` 里的全部引脚。电机和逻辑分开供电、
单点共地，电机侧并一个 470µF 以上的电解电容。

电机铭牌上的减速比和编码器 PPR 要如实填进配置。这两个数字填错，整条角度链会按比例偏，
而且症状不直观。

发射器相关代码在完成安全评审前不要接真实装置。
